# 图文同步助手

Chrome 扩展原型，用于准备和同步图文到小红书、抖音创作者后台。使用浏览器中已登录的账号。

## 当前状态

这是开发中的原型，不保证平台页面变动后仍可正常使用。标题、正文、图片、话题和声明的自动处理尚未完成全面验证；发布后的结果也不会自动确认。小红书话题候选和后台页面控件识别的近期修改尚待实测。不要将其用于无人值守的自动发布。

## 安装和使用

1. 下载仓库并解压，在 Chrome 打开扩展程序管理页面，启用开发者模式。
2. 选择“加载未打包的扩展程序”，选择本目录（直接包含 `manifest.json`）。不要选择整个仓库目录。
3. 点击工具栏中的“图文同步助手”，填写标题、正文、话题并选择图片和目标平台。首次使用保持“测试模式”勾选，检查平台预览和提示。
4. 关闭测试模式会尝试点击平台发布按钮；点击后须在平台内容管理中核实结果，结果不明时不要重复提交。原创声明须按实际内容和平台规则选择，平台要求确认须知时会停止等待处理。

## 本地通信

`bridge.cjs` 和 `native-host.cjs` 是 Windows 上的实验性本地通信组件。它们需要 Node.js，以及与实际扩展 ID 和本机路径匹配的 Chrome Native Messaging 宿主配置；仓库不包含任何用户机器的注册表配置或专用路径。未配置时，扩展界面仍可打开，本地桥接不可用。桥接当前只支持连接检查及测试填入，不支持通过桥接发布。

本仓库不包含账号凭据、用户素材或本机状态数据库。
